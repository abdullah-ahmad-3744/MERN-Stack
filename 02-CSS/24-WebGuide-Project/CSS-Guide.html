Learn CSS Basics

Learn CSS which is used to styling web pages and make them attractive

What is CSS?

CSS stands for Cascading Style Sheet. It is used to style the html elements. It ensures how elements will be displayed on web pages. It gives the colors, background colors , fonts, etc to the html elemets

  • CSS is used to style to web pages
  • It is used to add colors, background colors, fonts, etc
  • It is used to make the web pages visually attractive

Common CSS Properties

Selectors

Selectors in CSS are used to target and style specific HTML elements. Selectors can be based on element names, classes , id's and attributes of an element.

Colors and Background Colors

In CSS color property is used for text colors of an element.

The background color property defines te background color of an element improving visuals and readibility of an element.

Text Styling

Text styling in CSS involves different properties like font-size, font-weight, color and alignment of the text. It increases user experience of the pages.

Box Model

Box model represents how elements are structured on a web page using these parts: content, margin, padding, border. Box model treats all the content in a box from.

FlexBox Layout

In CSS flex box is a laylout model which arranges elements in the container when their sizes are dynamic. Flex box consist of properties like flex , justify-contnet, align-itmes for the flexible arrangement of elements

Grid Layout

Grid layout in CSS is a two dimensional system for creating and responsive layouts. Rows and coloumn are used in it controlled by different properties like grid-template-colomn and grid-template-rows.

CSS Animations

Animations allow an elemnet to flow in between different states. Animations make the elements visually attractive and esthatic. Different properties like animation name, animation duration, animation timing function are used to control the animations.

CSS Keyframes

Keyframes are used to with animations. These are used to control and define the dofferent stages of an animation.

Responsive Design

In CSS responsive design ensures that the web pages will be adjusted according to different screen sizes. It uses media queries. It improves the usebility of the website accross different devices.
