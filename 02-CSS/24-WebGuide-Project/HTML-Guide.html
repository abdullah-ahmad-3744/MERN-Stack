Learn HTML which is the building block of the web development.

What is HTML?

HTML stands for Hyper Text Makrup Language. It is used to create the structure of the web pages and display their content with the use of different elements represented by various tags

HTML provides the basic strucutre of the website which will be further enhanced and modified by other technologies like CSS , javaScript and their frameworks and libraries

  • HTML is used to create the web page structure
  • It uses different tags to create different parts of a web page
  • HTML documents are tree like structure
  • HTML is the basics of any website

Common HTML Elements

Headings

In HTML headings are used to define to titles and subtitiles of the web page. There are 6 heading tags from h1 to h6. Headings tags are h1 , h2 , h3 ,h4, h5, h6.

Paragrapgh

A paragrapgh in HTML is used to structure and display the text context. It increases the readibility of the text by adding before and after spacing.

Links

Links are used to create Hyper links , using these hyper links users can navigate from one page to another page.

Imgages

Images in HTML used to embed pictures in the web pages. In images " src " sttribute is used to define image source and alt provides alternative text about image.

Lists

Lists are used to organize HTML elemets. Two types of lists are Ordered Lists and Un-Ordered Lists

forms

HTML forms are used for collecting data from usrers. Forms contain elements like inputs, checkboxes, radio buttons and submit buttons

Semantics

HTML semantics are very useful for creating web pages. Semantics improve readibility and are SEO friendly.
